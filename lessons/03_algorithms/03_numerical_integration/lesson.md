# Методы численного интегрирования

Пусть дана функция $f(x)$, определенная и непрерывная на отрезке $[a, b]$. Задача численного интегрирования заключается в вычислении определенного интеграла
$$ I = \int_{a}^{b} f(x) \, dx. $$

Хотя существуют методы аналитического вычисления интегралов, в некоторых случаях это может быть затруднительно или невозможно. В таких случаях применяют численные методы интегрирования.

## Метод прямоугольников

Метод прямоугольников основан на аппроксимации интеграла с помощью суммы площадей прямоугольников. Для этого отрезок $[a, b]$ разбивается на $n$ равных частей, и на каждом отрезке $[x_i, x_{i+1}]$ выбирается точка $x_i^*$, в которой вычисляется значение функции $f(x_i^*)$. Площадь прямоугольника, соответствующая отрезку $[x_i, x_{i+1}]$, равна $$f(x_i^*) \cdot \Delta x,\quad \Delta x = \frac{b - a}{n}.$$

Итоговое значение интеграла равно сумме площадей всех прямоугольников:

$$ I \approx \sum_{i=0}^{n-1} f(x_i^*) \cdot \Delta x. $$

Точку $x_i^*$ можно выбирать по-разному:

- $x_i^* = x_{i}$ $-$ метод левых прямоугольников,
- $x_i^* = x_{i+1}$ $-$ метод правых прямоугольников,
- $x_i^* = (x_i + x_{i+1}) / 2$ $-$ метод средних прямоугольников.

Формула для метода средних прямоугольников:
$$ I \approx \sum_{i=0}^{n - 1} f(x_i) \cdot \Delta x,\quad \Delta x = \frac{b - a}{n},\quad x_i = a + (i + 0.5) \cdot \Delta x. $$

Для метода средних прямоугольников справедлива следующая оценка погрешности:
$$ |I - I_n| \leq \frac{(b - a)^3}{24n^2} \max_{x \in [a, b]} |f''(x)|. $$

Пример кода для метода средних прямоугольников:

```с
double rectangle(double a, double b, unsigned long long n, double (*f)(double)) {
    if (n == 0) return 0.;

    double dx = (b - a) / n;
    double I = 0.;
    for (unsigned long long i = 0; i < n; ++i) {
        I += f(a + (i + 0.5) * dx);
    }
    return I * dx;
}
```

## Метод трапеций

Метод трапеций основан на аппроксимации интеграла с помощью суммы площадей трапеций. Для этого отрезок $[a, b]$ разбивается на $n$ равных частей, и на каждом отрезке $[x_i, x_{i+1}]$ вычисляются значения функции $f(x_i)$ и $f(x_{i+1})$. Площадь трапеции, соответствующая отрезку $[x_i, x_{i+1}]$, равна
$$\frac{f(x_i) + f(x_{i+1})}{2} \cdot \Delta x,\quad \Delta x = \frac{b - a}{n}.$$

Итоговое значение интеграла равно сумме площадей всех трапеций:

$$ I \approx \sum_{i=0}^{n-1} \frac{f(x_i) + f(x_{i+1})}{2} \cdot \Delta x. $$

Для вычисления, формулу можно переписать в виде:
$$ I \approx (\frac{f(a) + f(b)}{2} + \sum_{i=1}^{n-1} f(x_i)) \cdot \Delta x,\quad \Delta x = \frac{b - a}{n},\quad x_i = a + i \cdot \Delta x. $$

Для метода трапеций справедлива следующая оценка погрешности:
$$ |I - I_n| \leq \frac{(b - a)^3}{12n^2} \max_{x \in [a, b]} |f''(x)|. $$

Пример кода для метода трапеций:

```с
double trapezoidal(double a, double b, unsigned long long n, double (*f)(double)) {
    if (n == 0) return 0.;

    double dx = (b - a) / n;
    double I = 0.;
    for (unsigned long long i = 1; i < n; ++i) {
        I += f(a + i * dx);
    }
    return ((f(a) + f(b)) / 2 + I) * dx;
}
```

## Метод Симпсона

Метод Симпсона основан на аппроксимации интеграла с помощью суммы площадей парабол. Для этого отрезок $[a, b]$ разбивается на $n$ равных частей, и на каждом отрезке $[x_i, x_{i+1}]$ вычисляются значения функции $f(x_i)$, $f(x_{i+0.5})$ и $f(x_{i+1})$. Площадь параболы, соответствующая отрезку $[x_i, x_{i+1}]$, равна
$$\frac{f(x_i) + 4f(x_{i+0.5}) + f(x_{i+1})}{6} \cdot \Delta x,\quad \Delta x = \frac{b - a}{n}.$$

Итоговое значение интеграла равно сумме площадей всех парабол:
$$ I \approx \sum_{i=0}^{n-1} \frac{f(x_i) + 4f(x_{i+0.5}) + f(x_{i+1})}{6} \cdot \Delta x. $$

Для вычисления, формулу можно переписать в виде:
$$ I \approx (f(a) + 2 \sum_{i=1}^{n-1} f(x_i) + 4 \sum_{i=0}^{n-1} f(x_{i+0.5}) + f(b)) \cdot \Delta x / 6,$$
$$\Delta x = \frac{b - a}{n},\quad x_i = a + i \cdot \Delta x,\quad x_{i+0.5} = a + (i + 0.5) \cdot \Delta x. $$

Для метода Симпсона справедлива следующая оценка погрешности:
$$ |I - I_n| \leq \frac{(b - a)^5}{180n^4} \max_{x \in [a, b]} |f^{(4)}(x)|. $$

Пример кода для метода Симпсона:

```с
double simpson(double a, double b, unsigned long long n, double (*f)(double)) {
    if (n == 0) return 0.;
    
    double dx = (b - a) / n;
    double I_odd = f(a + 0.5 * dx), I_even = 0.;
    for (unsigned long long i = 1; i < n; ++i) {
        I_even += f(a + i * dx);
        I_odd += f(a + (i + 0.5) * dx);
    }
    return (f(a) + 2 * I_even + 4 * I_odd + f(b)) * dx / 6;
}
```

## Примечания

- Все методы численного интегрирования, кроме методов Монте-Карло, являются детерминированными.
- В каждом методе указано, что отрезок $[a, b]$ разбивается на $n$ частей, хотя в общем случае, длина каждого отрезка может быть различной.
- С точки зрения интерполяции, метод прямоугольников аппроксимирует функцию константой, метод трапеций - линейной функцией, метод Симпсона - квадратичной функцией.
- Методы численного интегрирования можно обобщить на случай многомерных интегралов, хотя в этом случае возникают дополнительные трудности. Для интегрирования функций многих переменных преимущественно используют методы Монте-Карло.
