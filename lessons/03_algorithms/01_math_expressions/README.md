# Интерпретатор математических выражений

## Описание

Программа представляет собой интерпретатор математических выражений. Она преобразовывает входную строку во внутреннее представление для дальнейшего вычисления. 

Поддерживаемые операции:

- Бинарные операции (сложение, вычитание, умножение, деление, возведение в степень)
- Унарные операции (унарный плюс, унарный минус)
- Скобки
- Функции (sin, cos, log, exp, pow) и пользовательские функции
- Переменные и константы (pi, e)

Подробнее о работе программы можно прочитать в [документации](lesson.md).
