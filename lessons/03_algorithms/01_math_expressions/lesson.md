# Интерпретатор математических выражений

## Описание

Интерпретатор математических выражений - это программа, которая принимает на вход строку, содержащую математическое выражение, и преобразовывает его во внутреннее представление. После этого программа может производить различные операции над этим выражением, например, вычислять его значение, упрощать, выводить в виде строки и т.д.

## Этапы работы интерпретатора

Рассмотрим основные этапы работы интерпретатора математических выражений:

1. **Лексический анализ** - разбиение входной строки на последовательность лексем (токенов). Лексемы могут быть числами, идентификаторами переменных, операторами и т.д.
2. **Синтаксический анализ** - построение синтаксического дерева (AST) на основе лексем. Синтаксическое дерево представляет собой иерархическую структуру, в которой узлы соответствуют операциям, а листья - операндам.
3. **Интерпретация** - выполнение операций над синтаксическим деревом (например, вычисление значения выражения).

### Процесс лексического анализа

Лексический анализатор в цикле выполняет следующие действия:

1. Считывает очередной символ из входной строки.
2. Определяет тип лексемы, начинающейся с этого символа:
   - Если символ - пробел, то он игнорируется.
   - Если символ - цифра, то лексема - число.
   - Если символ - буква, то лексема - идентификатор (переменная или функция).
   - Иначе, лексема - оператор или разделитель. Лексер проверит, является ли текущая подстрока действительным оператором или разделителем.
3. Добавляет лексему в список токенов.
4. Повторяет шаги 1-3 до тех пор, пока не достигнет конца строки.

### Процесс синтаксического анализа

Синтаксический анализатор работает на основе рекурсивного спуска. Он строит синтаксическое дерево, используя правила грамматики математических выражений. Упрощенная грамматика выражений может быть следующей:

```ebnf
expression = binary | unary | func | group | var | number
binary = expression op expression
unary = op expression
func = id '(' expression_list ')'
group = '(' expression ')'
var = id
number = int | float
```

Полное описание грамматики можно найти в [этом файле](grammar.md).


## Структуры данных в интерпретаторе

### Токены

Токен (лексема) - это минимальная единица, которую можно выделить во входной строке. Токены могут быть различных типов: числа, операторы, переменные и т.д. Для представления токена можно использовать следующую структуру:

```c
typedef enum {
    TOKEN_ID, // идентификатор (переменная)
    TOKEN_NUMBER, // число (целое или вещественное)
    TOKEN_PLUS, TOKEN_MINUS, TOKEN_STAR, TOKEN_SLASH, TOKEN_CARET, // операторы
    TOKEN_COMMA, TOKEN_LPAREN, TOKEN_RPAREN // разделители
    TOKEN_END // служебный токен для обозначения конца строки
} TokenType;

typedef struct {
    TokenType type;
    char *value; // значение токена (важно для чисел и переменных)
} Token;
```

### Синтаксическое дерево

Синтаксическое дерево (Abstract Syntax Tree, AST) - это структура данных, которая представляет собой иерархическое дерево, в котором узлы соответствуют операциям, а листья - операндам. Для представления синтаксического дерева можно использовать следующую структуру:

```c
typedef enum {
    NODE_BINARY, // бинарная операция
    NODE_UNARY, // унарная операция
    NODE_FUNC, // функция
    NODE_GROUP, // выражение в скобках
    NODE_VARIABLE // переменная
    NODE_NUMBER, // число
} NodeType;

typedef struct ASTNode {
    NodeType type;

    union {
        struct {
            char op; // оператор
            struct ASTNode *left, *right; // операнды
        } binary; // для NODE_BINARY
        
        struct {
            char op; // оператор
            struct ASTNode *operand; // операнд
        } unary; // для NODE_UNARY

        struct {
            char *name; // имя функции
            size_t argc; // количество аргументов
            struct ASTNode **args; // аргумент функции
        } func; // для NODE_FUNC

        struct ASTNode *group; // для NODE_GROUP
        char *name; // для NODE_VARIABLE
        double number; // для NODE_NUMBER
    };
} ASTNode;
```

## Variable & Function

Для дальнейшей работы с переменными и функциями реализованы следующие структуры:

```c
typedef struct {
    char *name;
    double value;
} Variable;

typedef struct {
    char *name;
    double (*func)(size_t, double *); // функция может принимать переменное количество аргументов
} Function;
```

## Пример работы интерпретатора

- Вход: `2 + 3 * x`
- Лексический анализ: `[2, +, 3, *, x]`
- Синтаксический анализ: `Binary('+', 2, Binary('*', 3, Variable('x')))`
- Интерпретация: (`x = 5`) -> `2 + 3 * 5 = 17`

## Структура программы

Программа, реализующая интерпретатор математических выражений, может быть разделена на следующие модули:

### Заголовочные файлы

- [`token.h`](code/inc/token.h) - определение структуры токена
- [`ast.h`](code/inc/ast.h) - определение структуры синтаксического дерева
- [`expression.h`](code/inc/expression.h) - определение структуры математического выражения и функций для его обработки

### Исходные файлы

- [`ast.c`](code/src/ast.c) - реализация функций для работы с синтаксическим деревом
- [`lexer.c`](code/src/lexer.c) - реализация функций для лексического анализа
- [`parser.c`](code/src/parser.c) - реализация функций для синтаксического анализа
- [`expression.c`](code/src/expression.c) - реализация функций для работы с математическими выражениями
- [`evaluation.c`](code/src/evaluation.c) - реализация функций для вычисления значения выражения
